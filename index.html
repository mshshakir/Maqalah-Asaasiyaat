تفسير الكلمات المفقودة

يرجى توضيح سبب وجود الكلمات التالية:

دليل الاستخدام / User Guide
1. الصفحة الرئيسية (العنوان والسؤال)
  • الإدخال: أدخل "عنوان المقالة" و "السؤال الرئيسي".
  • التحليل: اضغط زر "تحليل". الكلمات المفقودة ستظهر باللون الأحمر.
  • الأسباب: وضح سبب غياب الكلمات في النافذة المنبثقة.
2. صفحة الأسئلة الفرعية
  • إضافة قسم: أضف أبوابًا جديدة.
  • البيانات: أدخل "اسم الباب"، "الأهداف"، و "السؤال الفرعي".
  • تحليل الكل: افحص تطابق الكلمات في جميع الأقسام.
3. صفحة الهيكلية التفصيلية
  • بناء الهيكلية: أضف فصولًا، مباحث، ومطالب لكل باب.
4. التصدير
  • HTML: معاينة وطباعة (جداول + هوامش).
  • Word/Excel: تحميل الملفات.
1. Main Page (Title & Main Question)
  • Input: Enter "Article Title" and "Main Question".
  • Analyze: Click "Analyze". Missing words appear in Red.
  • Reasons: Explain missing words in the popup.
2. Sub-Questions Page
  • Add Section: Add new "Abwaab" (Chapters).
  • Data: Enter "Abwaab Names", "Objectives", and "Sub-Question".
  • Analyze All: Check for missing words across sections.
3. Structure Page
  • Build Hierarchy: Add Fasl, Mabhath, and Matlab items.
4. Export
  • HTML: Preview & Print (Tables + Footnotes).
  • Word/Excel: Download files.
